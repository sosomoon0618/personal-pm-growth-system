## 项目与产品实践 Base

| 表 | 管理对象 | 关键边界 |
|---|---|---|
| 项目档案 | 项目索引、上下文卡入口、个人资产完善状态 | 不代表项目业务开发状态 |
| 可复用项目证据 | 可支撑叙事、回答、复盘或 SOP 的关键事实 | 非项目资料全量归档；每条要有来源与适用范围 |
| 需求复盘候选与高价值复盘 | 高价值判断、生命周期资料入口、状态和个人反思入口 | 候选／不纳入不是高价值复盘本身 |
| SOP／方法论资产 | 顶层方法论入口、来源、适用场景与验证状态 | 不复制 SOP 正文 |

## 面试与成长运营 Base

| 表 | 管理对象 | 关键边界 |
|---|---|---|
| 母题与答案资产 | 可复用母题、同义问法、口头答案、核心追问、主题／方向／项目关联 | 不是每次真实提问的流水账 |
| 岗位准备包（存在具体 JD 时） | 特定公司与职位的 JD 解析、预测题和准备状态 | 预测题可不关联母题；不把业务方向当成单一固定组合 |
| 面试场次 | 整场信息、轮次、面试官／角色、性质、结果、整场结论与直接反馈 | 不代替原始记录或复盘正文 |
| 实际问题与复盘 | 值得处理的问题、完整原始问答、关联母题、根因与处理决策 | 仅收录需要复盘、沉淀或行动的问题 |
| 改进建议与行动 | 具体可执行行动或暂不能执行的建议、来源、节奏、验证状态 | 不等同于母题练习；不等同于能力已提升 |
| 能力短板与验证 | 长期能力主题、基线、方案、可观察标准和验证证据 | 不为每道题或每项行动创建一条能力记录 |

## 关键关联规则

1. 项目证据可支持母题答案、项目上下文卡、高价值需求复盘和 SOP，但不自动复制正文。
2. 真实问题可以关联一个或多个母题，也可以暂不关联；重复出现或具跨场景价值时才建议提升为母题。
3. 一场面试可以产生多条改进建议；一条行动可来自整场或单题；能力主题可关联多个场次、问题和行动。
4. SOP 的真实使用和验证可由需求复盘、项目证据或后续面试表现提供；没有可回查证据时保持“待实际应用”。
